# Employee Data Analysis using Pandas

## Project Overview

This project demonstrates the fundamentals of data analysis using Python and Pandas.

## Topics Covered

- Data Exploration
- Data Selection
- Data Filtering
- Missing Value Handling
- Duplicate Handling
- Data Transformation
- Sorting
- GroupBy
- Merge
- Pivot Table
- Melt
- Exporting Data to CSV

## Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
